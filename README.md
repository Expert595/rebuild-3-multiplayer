# Rebuild 3 Multiplayer

Version: 5.

Requires your own copy of the game. Includes mod components and required replacement files, not a complete game installation.

## Installation and usage

Requires an existing Rebuild 3 v1.6.40 installation, as specified by the supplied package. Back up the files being replaced. Copy this repository's mod files into the game folder, replacing `Rebuild3.swf`.

Host: run `Run Multiplayer Host.bat`, then select Host in the Multiplayer Menu.

Local client: run `Run Multiplayer Client Local.bat`, then select Join.

LAN or remote client: run `Run Multiplayer Client Remote.bat`, enter the host address, then select Join.

If needed, run `Allow Multiplayer Port 31337.bat` once as Administrator. Both players must use the same build.
